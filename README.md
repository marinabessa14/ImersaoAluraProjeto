# Melhores Dicas e Recomendações

[![Demonstração do Projeto (Clique para assistir)](https://www.youtube.com/watch?v=RR7wxkl8lX4)

Este projeto é uma aplicação web interativa construída com Python e Gradio para coletar, analisar e visualizar recomendações de usuários em diversas categorias. A interface intuitiva permite que qualquer pessoa compartilhe suas dicas e explore as contribuições de outros.

## Funcionalidades Principais:

* **Compartilhamento de Dicas:** Adicione facilmente suas recomendações, especificando a categoria, o item recomendado e uma breve descrição do porquê.
* **Filtragem Dinâmica:** Explore as dicas por categoria específica ou filtre por sentimento (Positivo, Negativo, Neutro) das descrições.
* **Análise de Dados Textuais:** Obtenha insights valiosos através de:
    * **Lista de Dicas Filtradas:** Visualize as recomendações que correspondem aos seus critérios de busca.
    * **Popularidade das Categorias:** Descubra quais tipos de dicas são mais frequentes.
    * **Distribuição de Sentimentos:** Entenda o tom geral das opiniões e recomendações.
    * **Nuvem de Palavras:** Identifique os termos mais relevantes e mencionados nas recomendações.

## Tecnologias Utilizadas:

* Python
* Gradio
* Pandas
* TextBlob
* WordCloud
* Matplotlib
